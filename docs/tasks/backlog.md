## Task Queue (`T-001` → `T-052`)

`T-039`–`T-042` were added by the 2026-10-30 completeness audit (SPEC §8 step 4, §12, §19, §20 gaps). To keep them inside their milestones under the lowest-number rule, `T-039`/`T-040` were added to `T-029`'s `Deps` (MVP exit) and `T-041`/`T-042` to `T-037`'s `Deps` (beta tag).

`T-043`–`T-045` were added by the 2026-10-31 integrity & trajectory audit (approved by Lucas Pan): `T-043` owns the unassigned §8 spawn step 4 coord-ref registry (dep of `T-029`); `T-044` fixes locale-dependent push-race classification and untested retry exhaustion (dep of `T-018`); `T-045` restores the §20 Week-4 real two-agent exit to M3 (dep of `T-030`, `ADR-0004`). The same audit made `T-031`'s coverage bar a CI-enforced job and added the §10 step 4 idle quarantine retry to `T-024`.

`T-046` was added with the acceptance of `ADR-0007` (2026-10-31, Lucas Pan): the Unix socket path-length fallback. It is a dependency of `T-029` so the MVP exit cannot land while deep repository paths still break the daemon on macOS/Linux.

`T-047` was added at Lucas Pan's request (2026-11-02) to close the open note of `T-043`: the coordination-ref task registry was published only by `spawn`, failed spawns and `abort` (that task's scope fence), so a task merged or swept by the daemon kept its last published status on other machines. It gives `ADR-0008`'s cross-machine view of tasks accurate states.

`T-048` and `T-049` were added with the acceptance of `ADR-0009` (2026-11-02, Lucas Pan, both parts): `T-034`'s benchmark showed local claims far over the §18 p95 < 50 ms budget on every OS (99 / 856 / 1804 ms) because each daemon claim ran a synchronous coordination sync costing about 2N + L + 8 git subprocesses. `T-048` makes sync rounds independent of log length; `T-049` lets the daemon answer from memory after a WAL append and commit in the background.

`T-050`–`T-052` were added by the 2026-11-03 alignment audit with the acceptance of `ADR-0010` and `ADR-0011` (Lucas Pan): `T-050` implements coordination-log compaction (claim latency independent of repository age); `T-051` is the full-scale benchmark run `T-034` left open (2 GB `node_modules`, real remote, baseline sized so N > 0), a dependency of `T-036` and `T-037`; `T-052` implements the `ADR-0011` config keys, OS machine-id derivation and `.venv` policy. The same audit removed `T-045` from `T-030`'s deps (the human run no longer stalls the agent chain) and made it a dependency of `T-037` instead, added the untested §17 IPC checks to `T-031`, and extended `T-033` to the `ADR-0008`/`0009`/`0010` protocol changes.
