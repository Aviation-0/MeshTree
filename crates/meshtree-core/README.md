# meshtree-core

The pure, deterministic core of [MeshTree](https://github.com/Aviation-0/MeshTree): task model and lifecycle, lease events and replay, path-pattern conflicts, the shared-op queue and handoff rendering. No filesystem, process or network access.

An internal crate of the `meshtree` binary; its API is not yet stable.
