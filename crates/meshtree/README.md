# meshtree

The MeshTree binary: `meshtree daemon`, the `meshtree` CLI and the `meshtree mcp` stdio server, which coordinate parallel AI coding agents across git worktrees and machines.

See the [project README](https://github.com/Aviation-0/MeshTree) and [`SPEC.md`](https://github.com/Aviation-0/MeshTree/blob/main/SPEC.md).
