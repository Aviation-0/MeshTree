# meshtree-platform

The platform layer of [MeshTree](https://github.com/Aviation-0/MeshTree): git plumbing behind the `GitOps` trait, coordination-ref sync with CAS, daemon IPC (Unix sockets and named pipes), the daemon lock, the write-ahead log, worktree teardown and dependency sharing.

An internal crate of the `meshtree` binary; its API is not yet stable.
